What this model cannot tell you

  
No platform publishes the distribution of RTO rates across its sellers.
     It is the one input this scheme needs and the one we cannot obtain from outside. If every seller sits
     between 15% and 19%, there is nothing to redistribute. If the spread runs 5% to 40%, the scheme is
     powerful. The seller scorecard in days 0–30 produces that distribution — and the levy does
     not switch on until it does. This calculator is therefore a rate card, not a forecast.

What this prototype does and does not do

  
Stops sit on a synthetic grid, not real road geometry or live traffic —
     a published page cannot call a mapping API, so this is a coordinate-plane stand-in for one. The
     optimiser itself is real: nearest-neighbour construction followed by 2-opt improvement, the standard
     approach for a single-vehicle routing problem this size. Wired to an actual roads API (for real
     distances) and a live order feed (for real stops and time windows), the same algorithm is the one a
     production version would run.
